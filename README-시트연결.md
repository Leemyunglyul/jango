# 구글 시트를 저장소로 붙이기

앱은 그대로 두고 **데이터만 내 구글 드라이브 시트에 쌓이게** 하는 설정이다.
한 번 해두면 폰에서 기록한 게 PC에서 보이고, 앱을 지워도 시트는 남는다.

전체 10분. 코딩은 없고 붙여넣기만 한다.

---

## 1. 스프레드시트 만들기

브라우저에서 <https://sheets.new> → 이름을 **가계부 2026** 같은 걸로 바꾼다.
탭(거래·설정·자산·종목·스냅샷)은 스크립트가 알아서 만드니 손대지 않는다.

## 2. Apps Script 열기

메뉴 → **확장 프로그램 → Apps Script**

## 3. 코드 붙여넣기

편집기에 있는 `function myFunction() {}` 를 **전부 지우고**,
`apps-script/코드.gs` 파일 내용을 통째로 붙여넣는다. 저장(Ctrl/Cmd+S).

## 4. 토큰 넣기

왼쪽 **⚙️ 프로젝트 설정** → 아래 **스크립트 속성** → **스크립트 속성 추가**

| 속성 | 값 |
|---|---|
| `TOKEN` | `QnpEdCmoUInO6RNkClEMT0Hb` |

위 값은 방금 만들어 둔 무작위 문자열이다. 그대로 써도 되고 직접 정해도 되는데,
**짧게 만들지 말 것** — 이게 유일한 자물쇠다. 저장을 누른다.

## 5. 웹 앱으로 배포

오른쪽 위 **배포 → 새 배포** → 톱니바퀴(유형 선택) → **웹 앱**

| 항목 | 값 |
|---|---|
| 설명 | 아무거나 (예: v1) |
| 실행 계정 | **나** |
| 액세스 권한이 있는 사용자 | **모든 사용자** ← 이게 핵심 |

**배포** 를 누르면 권한 승인 창이 뜬다. 내 계정 선택 →
"Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트명)(으)로 이동** →
**허용**. 내가 만든 스크립트라 정상이다.

끝나면 **웹 앱 URL** 이 나온다. `.../exec` 로 끝나는 주소를 복사한다.

> ⚠️ "액세스: 모든 사용자"는 로그인 없이 접근하게 하려고 필요한 설정이다.
> 대신 URL을 아는 사람이 접근할 수 있으니 **토큰이 실제 자물쇠**다.
> URL과 토큰을 같이 공개된 곳에 올리지 말 것. (GitHub 레포에도 넣지 않는다 —
> 앱은 이 값을 코드가 아니라 브라우저에만 저장한다.)

## 6. 앱에 연결

앱 → **설정 → 동기화 → 구글 시트 연결하기** →
URL과 토큰을 붙여넣고 **연결 확인**.

- 시트가 비어 있으면 → 지금 앱에 있는 내용을 시트로 올린다
- 시트에 이미 데이터가 있으면 → 어느 쪽을 남길지 물어본다

성공하면 상단에 **● 시트 14:23** 같은 칩이 뜬다. 이게 마지막 저장 시각이다.

## 7. 폰에서도 한 번 더

폰 브라우저로 같은 사이트를 열고 **설정 → 동기화**에서 같은 URL·토큰을 입력한다.
URL·토큰은 기기마다 따로 저장되니까(그래서 안전하다) 기기당 한 번씩만 하면 된다.
그다음 **홈 화면에 추가**.

---

## 시트가 어떻게 생겼나

| 탭 | 내용 |
|---|---|
| **거래** | 날짜 · 월 · 구분 · 분류 · 금액 · 메모 · 일회성 · ID · 분류ID |
| **자산** | 이름 · 구분 · 평가액 · 누적 납입원금 · 월납입 · 대출잔액 · 메모 · ID · 구분ID |
| **종목** | 계좌 · 종목 · 수량 · 평단가 · 현재가 · 평가액 · 평가손익 · 계좌ID · 시세코드 · 원시세 · 통화 · 적용환율 · 시세갱신 |
| **스냅샷** | 월별 투자 기록: 납입 · 인출 · 평가액 · 원금 · 시장손익 · 수익률 · 메모 · 보유종목(JSON) |
| **설정** | 카테고리·예산·고정비·퀵버튼을 JSON 한 줄씩 |

**거래** 탭이 피벗용으로 만들어져 있다. 날짜가 진짜 날짜값이고 `월` 열이 따로 있어서
삽입 → 피벗 테이블에서 행 `월`, 열 `분류`, 값 `금액 합계` 만 넣으면
예전 엑셀이랑 똑같은 표가 바로 나온다.

> 시트에서 값을 직접 고쳐도 된다. 앱에서 **설정 → 동기화 → 시트에서 내려받기** 하면 반영된다.
> 단 **ID 열은 지우지 말 것** (지우면 그 줄이 새 기록으로 취급된다).

## 무료 시세 연결

최신 `코드.gs`(백엔드 v4)를 배포하면 월별 투자 기록과 함께, 별도 API 키 없이 미국 종목·환율은
`GOOGLEFINANCE`, 국내 종목은 네이버 증권 공개 시세로 조회할 수 있다.
앱의 종목 등록/수정 화면에서 시세코드를 입력한다.

- 미국: `NASDAQ:QQQ`, `NYSEARCA:VOO`
- 국내 유가증권: `KRX:005930`
- 국내 코스닥: `KOSDAQ:247540`

미국 종목은 달러 현재가와 원/달러 환율을 저장하고, 앱의 원화 현재가는
`달러 현재가 × 환율`로 계산한다. Apps Script 코드를 바꾼 뒤에는 반드시
**배포 관리 → 연필 → 버전: 새 버전 → 배포**까지 해야 한다.

## 자주 걸리는 것

**"배포 설정에서 액세스 권한을 모든 사용자로…" 라고 뜬다**
5번에서 액세스가 "나만" 또는 "Google 계정이 있는 모든 사용자"로 돼 있다.
배포 관리 → 연필(편집) → 액세스를 **모든 사용자**로 바꾸고 **배포**.

**"토큰이 일치하지 않습니다"**
스크립트 속성의 `TOKEN` 값과 앱에 넣은 값이 다르다. 앞뒤 공백도 확인.

**코드를 고쳤는데 반영이 안 된다**
Apps Script는 저장만으로는 안 바뀐다. **배포 관리 → 연필 → 버전: 새 버전 → 배포**.
("새 배포"를 누르면 URL이 새로 생기니 주의.)

**상단 칩이 빨간 "동기화 실패"다**
네트워크가 끊겼거나 배포가 내려간 상태다. 기록은 브라우저에 그대로 남아 있고
연결이 돌아오면 다음 저장 때 밀린 것까지 같이 올라간다. 급하면
**설정 → 동기화 → 시트로 올리기**.
