# 구글 시트를 저장소로 붙이기

앱은 그대로 두고 **데이터만 내 구글 드라이브 시트에 쌓이게** 하는 설정이다.
한 번 해두면 폰에서 기록한 게 PC에서 보이고, 앱을 지워도 시트는 남는다.

전체 10분. 코딩은 없고 붙여넣기만 한다.

---

## 1. 스프레드시트 만들기

브라우저에서 <https://sheets.new> → 이름을 **가계부 2026** 같은 걸로 바꾼다.
탭(거래·설정·자산·종목·월별 투자기록)은 스크립트가 알아서 만든다.

## 2. Apps Script 열기

메뉴 → **확장 프로그램 → Apps Script**

## 3. 코드 붙여넣기

편집기에 있는 `function myFunction() {}` 를 **전부 지우고**,
`apps-script/코드.gs` 파일 내용을 통째로 붙여넣는다. 저장(Ctrl/Cmd+S).

## 4. 토큰 넣기

왼쪽 **⚙️ 프로젝트 설정** → 아래 **스크립트 속성** → **스크립트 속성 추가**

| 속성 | 값 |
|---|---|
| `TOKEN` | `QnpEdCmoUInO6RNkClEMT0Hb` |

위 값은 방금 만들어 둔 무작위 문자열이다. 그대로 써도 되고 직접 정해도 되는데,
**짧게 만들지 말 것** — 이게 유일한 자물쇠다. 저장을 누른다.

## 5. 웹 앱으로 배포

오른쪽 위 **배포 → 새 배포** → 톱니바퀴(유형 선택) → **웹 앱**

| 항목 | 값 |
|---|---|
| 설명 | 아무거나 (예: v1) |
| 실행 계정 | **나** |
| 액세스 권한이 있는 사용자 | **모든 사용자** ← 이게 핵심 |

**배포** 를 누르면 권한 승인 창이 뜬다. 내 계정 선택 →
"Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트명)(으)로 이동** →
**허용**. 내가 만든 스크립트라 정상이다.

끝나면 **웹 앱 URL** 이 나온다. `.../exec` 로 끝나는 주소를 복사한다.

> ⚠️ "액세스: 모든 사용자"는 로그인 없이 접근하게 하려고 필요한 설정이다.
> 대신 URL을 아는 사람이 접근할 수 있으니 **토큰이 실제 자물쇠**다.
> URL과 토큰을 같이 공개된 곳에 올리지 말 것. (GitHub 레포에도 넣지 않는다 —
> 앱은 이 값을 코드가 아니라 브라우저에만 저장한다.)

## 6. 앱에 연결

앱 → **설정 → 동기화 → 구글 시트 연결하기** →
URL과 토큰을 붙여넣고 **연결 확인**.

- 시트가 비어 있으면 → 지금 앱에 있는 내용을 시트로 올린다
- 시트에 이미 데이터가 있으면 → 어느 쪽을 남길지 물어본다

성공하면 상단에 **● 시트 동기화 14:23** 같은 칩이 뜬다. 마지막 동기화 시각이다.
연결 후에는 기록·자산·종목·설정 등을 저장할 때 약 1초 뒤 자동으로 업로드한다.
설정의 **지금 시트로 올리기**를 매번 누를 필요는 없다.

## 7. 폰에서도 한 번 더

폰 브라우저로 같은 사이트를 열고 **설정 → 동기화**에서 같은 URL·토큰을 입력한다.
URL·토큰은 기기마다 따로 저장되니까(그래서 안전하다) 기기당 한 번씩만 하면 된다.
그다음 **홈 화면에 추가**.

## 시트가 어떻게 생겼나

| 탭 | 내용 |
|---|---|
| **거래** | 날짜 · 월 · 구분 · 분류 · 금액 · 메모 · 일회성 · ID · 분류ID |
| **자산** | 이름 · 구분 · 평가액 · 누적 납입원금 · 월납입 · 대출잔액 · 메모 · ID · 구분ID |
| **종목** | 계좌 · 종목 · 수량 · 평단가 · 현재가 · 평가액 · 평가손익 · 계좌ID · 시세코드 · 원시세 · 통화 · 적용환율 · 시세갱신 |
| **월별 투자기록** | 월 · 납입 · 인출 · 평가액 · 원금 · 시장손익 · 수익률 · 계좌별 평가액 · 메모 · 보유종목(JSON) · (v7) 순자산 · 현금 · 청약 · 부동산 · 보험 · 부채 |
| **월별 자산** (v7) | 월 · 기록일 · 순자산 · 부동산 제외 · 투자 평가액 · 투자 원금 · 구분별 금액 — 앱이 매달 자동으로 남기는 자산 합계, 한 달 한 줄 |
| **설정** | 카테고리·예산·고정비·퀵버튼을 JSON 한 줄씩 |

### 몇 년 써도 괜찮나 (용량)

구글 스프레드시트 한 파일은 **셀 1,000만 개**, 셀 하나는 **5만 자**까지다.

| 탭 | 1년에 쌓이는 양 (한 달 거래 100건 기준) | 1,000만 셀까지 |
|---|---|---|
| 거래 | 1,200줄 × 9열 ≈ 1만 셀 | 수백 년 |
| 월별 투자기록 · 월별 자산 | 12줄 × 25열 ≈ 300셀 | 사실상 무제한 |

용량보다 문제가 되는 건 **속도**와 **셀 하나에 몰아넣은 값**이라 백엔드 v7에서 이렇게 바꿨다.

- **거래는 바뀐 달만 올린다.** 예전에는 거래 하나만 고쳐도 몇 년 치 거래 전체를 매번
  올리고 탭을 통째로 다시 썼다. 기록이 쌓일수록 업로드가 커져 저장이 느려지고 시간 초과가 날 수 있었다.
  이제 고친 달의 거래만 보내고 시트는 그 달 줄만 갈아 끼운다.
- **월별 자산은 전용 탭에 한 달 한 줄.** 예전에는 `설정` 탭의 셀 하나에 JSON으로 넣어서
  15~20년쯤이면 5만 자 한도에 닿았다. v7로 올리면 첫 동기화 때 그 셀의 기록을 `월별 자산` 탭으로
  옮기고 셀은 비운다. 이 탭은 있는 달만 고치고 없는 달은 덧붙이며, 앱에 없는 달을 지우지 않는다.
- **월별 투자기록에 그 달 전체 자산도 남긴다.** 예전에는 투자 계좌 금액만 있어서, 다른 기기에서
  내려받으면 그 달의 현금·청약·순자산이 빠졌다. 오른쪽에 열을 덧붙였고 앞 열 순서는 그대로다.

v6 백엔드도 계속 동작한다(앱이 버전을 보고 예전 방식으로 보낸다). 다만 설정 → 동기화에
v7 업데이트 안내가 뜨니, 아래 순서로 한 번 다시 배포하면 된다.

1. Apps Script 편집기에서 기존 코드를 모두 지우고 새 `apps-script/코드.gs`를 붙여넣고 저장
2. **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** (URL·토큰은 그대로)
3. 앱을 새로고침 → 설정 → 동기화에 **백엔드 v8**로 보이면 끝

### 백엔드 v8 — 두 기기 동시 저장 보호 · 토큰 보호

- 앱이 저장할 때 **마지막으로 본 시트 변경 번호(rev)**를 같이 보낸다. 그사이 다른 기기가 먼저
  저장했으면 시트는 덮어쓰지 않고 돌려보내고, 앱은 시트를 다시 읽어 **거래 ID 단위로 합친 뒤** 다시 올린다.
  - 이 기기에서 고친 달: 내 기록 + 다른 기기가 추가한 기록 (이 기기에서 지운 기록은 되살리지 않는다)
  - 이 기기에서 안 고친 달: 시트(다른 기기) 내용 그대로
  - 설정·자산·월별 투자기록: 이 기기에서 고친 항목만 내 값, 나머지는 시트 값
- 앱을 꺼 둔 사이 다른 기기가 저장했고 이 기기에도 못 올린 변경이 있으면, 다음에 열 때 같은 방식으로 합친다.
- 토큰은 POST 본문으로만 받는다. 주소(`?token=`)로 보내면 거절한다 — 방문 기록·로그에 토큰이 남지 않게.

v7 이하 백엔드도 그대로 동작하지만, 두 기기에서 거의 동시에 저장하면 나중에 저장한 쪽이 이긴다.

백업은 앱의 설정 → 백업 파일(JSON)과 구글 시트의 **파일 → 버전 기록**으로 이중으로 남는다.

**거래** 탭이 피벗용으로 만들어져 있다. 날짜가 진짜 날짜값이고 `월` 열이 따로 있어서
삽입 → 피벗 테이블에서 행 `월`, 열 `분류`, 값 `금액 합계` 만 넣으면
예전 엑셀이랑 똑같은 표가 바로 나온다.

> 시트에서 값을 직접 고쳐도 된다. 앱을 시작할 때 자동으로 시트 내용을 다시 읽으며,
> 열어 둔 상태에서는 **설정 → 동기화 → 시트에서 내려받기**를 누르면 바로 반영된다.
> 단 **ID 열은 지우지 말 것** (지우면 그 줄이 새 기록으로 취급된다).

## 무료 시세 연결

최신 `코드.gs`(백엔드 v6)를 배포하면 별도 월별 투자기록 시트와 함께, API 키 없이 미국 종목·환율은
`GOOGLEFINANCE`, 국내 종목은 네이버 증권 공개 시세로 조회할 수 있다.
앱의 종목 등록/수정 화면에서 시세코드를 입력한다.

- 미국: `NASDAQ:QQQ`, `NYSEARCA:VOO`
- 국내 유가증권: `KRX:005930`
- 국내 코스닥: `KOSDAQ:247540`

국내 코드는 `379810`처럼 6자리만 입력해도 앱이 `KRX:`를 붙인다.
ISA의 KODEX 미국나스닥100은 `379810`, KODEX 미국S&P500은 `379800`이며,
두 종목은 이름의 띄어쓰기나 대소문자가 달라도 자동 연결한다. 앱 실행 시 기존 보유
종목의 빈 코드도 보정하며 수량·평단·기존 가격은 유지한다.

미국 종목은 달러 현재가와 원/달러 환율을 저장하고, 앱의 원화 현재가는
`달러 현재가 × 환율`로 계산한다. Apps Script 코드를 바꾼 뒤에는 반드시
**배포 관리 → 연필 → 버전: 새 버전 → 배포**까지 해야 한다.

기존 스프레드시트에 **투자 월별 평가** 탭이 있으면, 앱을 시작할 때 그 탭의
`당월 투자 납입액 / 누적납입원금 / ISA 평가액 / 해외 평가액 …` 열을 읽어
**월별 투자기록**에 없는 달만 자동으로 보충한다. 이미 저장된 달은 덮어쓰지 않는다.

## 자주 걸리는 것

**"배포 설정에서 액세스 권한을 모든 사용자로…" 라고 뜬다**
5번에서 액세스가 "나만" 또는 "Google 계정이 있는 모든 사용자"로 돼 있다.
배포 관리 → 연필(편집) → 액세스를 **모든 사용자**로 바꾸고 **배포**.

**"토큰이 일치하지 않습니다"**
스크립트 속성의 `TOKEN` 값과 앱에 넣은 값이 다르다. 앞뒤 공백도 확인.

**코드를 고쳤는데 반영이 안 된다**
Apps Script는 저장만으로는 안 바뀐다. **배포 관리 → 연필 → 버전: 새 버전 → 배포**.
("새 배포"를 누르면 URL이 새로 생기니 주의.)

**상단 칩이 빨간 "실패 · 재시도 대기"다**
네트워크가 끊겼거나 배포가 내려간 상태다. 기록은 브라우저에 그대로 남아 있고
최대 30초 간격으로 다시 시도한다. 오프라인에서는 기기에 보관했다가 인터넷이
다시 연결되면 자동으로 올린다. 앱을 바로 닫았어도 미전송 목록이 남아 다음 실행 때
이어서 올린다. 급하면 **설정 → 동기화 → 지금 시트로 올리기**.
