# 잔고와 흐름

개인 가계부 + 자산·투자 트래커. 의존성 없는 단일 HTML 앱 + PWA.

**탭 4개** — 기록 / 내역 / 통계 / 자산 (자산 안에서 `자산 | 투자` 전환)
설정은 모바일에서 상단 아이콘, 데스크톱에서 사이드바 맨 아래.

- **모바일**: 한 줄로 흐르는 세로 레이아웃 + 숫자패드.
  하단 탭은 아이콘+글자로 58px 높이, 안전영역(`env(safe-area-inset-bottom)`) 반영
- **데스크톱(≥1080px)**: 좌측 사이드바 + 2단 구성. 숫자패드가 사라지고 **키보드로 입력**한다
  (`0`–`9` 금액 · `⌫` 지우기 · `Enter` 기록 · `M` 메모 · `T` 지출↔수입 · `[` `]` 달 이동)
- **테마**: 상단 아이콘으로 시스템 → 밝게 → 어둡게 순환 (`localStorage["jango.theme"]`)

```
index.html              앱 전체 (HTML/CSS/JS 한 파일)
manifest.json           PWA 매니페스트 (홈 화면 추가용)
sw.js                   서비스 워커 (오프라인 캐시 — 앱 파일만, 데이터는 안 건드림)
icon-*.png              아이콘
apps-script/코드.gs     구글 시트 백엔드 (선택)
README-시트연결.md      ↑ 설치 안내 — 동기화를 쓰려면 여기부터
README-배포.md          GitHub에 올리고 주소 만드는 법
build.py                아티팩트용 소스 → 정적 index.html 빌드 스크립트
.nojekyll               GitHub Pages가 파일을 그대로 서빙하게
.gitignore              가계부 백업 파일이 실수로 커밋되는 걸 막음
```

외부 의존성은 두 개뿐이고 둘 다 CDN에서 로드한다.
- Google Fonts (Hahmlet, IBM Plex Sans KR, IBM Plex Mono)
- SheetJS 0.18.5 — 엑셀 내보내기에만 사용

## 1. 로컬에서 열기

```bash
python3 -m http.server 8080
# http://localhost:8080
```

`file://` 로 열어도 동작하지만 서비스 워커는 https(또는 localhost)에서만 등록된다.

## 2. 배포

GitHub에 올리고 주소를 만드는 전체 과정은 [README-배포.md](./README-배포.md)에 있다.
요약하면 레포 만들기 → 이 폴더의 **내용물**을 최상단에 올리기 →
Settings → Pages → `main / (root)` → 저장.

> 무료 GitHub 계정은 **공개 레포**에서만 Pages를 쓸 수 있다.
> 이 저장소에는 가계부 데이터도, 시트 URL·토큰도 들어가지 않으므로 공개해도 안전하다.
> 그래도 비공개로 두고 싶으면 Cloudflare Pages를 쓰면 된다 (배포 문서 마지막 절).

## 3. 데이터가 어디에 저장되나

저장 계층이 세 갈래로 자동 분기한다. 위에서부터 먼저 잡히는 걸 쓴다.

| 조건 | 저장소 | 기기 간 동기화 |
|---|---|---|
| 설정에서 구글 시트를 연결함 | **내 드라이브 스프레드시트** | **된다** |
| Claude 아티팩트로 열림 | `claude.use("db")` | 된다 |
| 그 외 (그냥 웹) | `localStorage` | 안 된다 |

**권장: 구글 시트 연결.** 설치는 [README-시트연결.md](./README-시트연결.md) 참고.
데이터가 내 드라이브에 남으니 이 앱을 지워도, 호스팅을 옮겨도 기록은 그대로다.
시트를 열어서 피벗을 돌리거나 직접 고쳐도 되고, 앱에서 다시 내려받으면 반영된다.

연결하지 않으면 `localStorage`라 그 브라우저에만 남는다. 폰에서 기록한 게
PC에 안 보이고, 사이트 데이터를 지우면 날아간다. 백업은 설정 → 백업 파일(JSON).

### 동기화가 도는 방식

- 기록하면 → 메모리 → `localStorage` 즉시 → **1.4초 디바운스 후** 시트에 저장
  (숫자패드 누를 때마다 요청을 보내지 않으려고)
- 앱을 열면 → `localStorage`로 먼저 그리고 → 시트를 읽어서 `rev`(수정 횟수)를 비교
  - 시트가 더 최신 → 시트 내용을 채택
  - 앱이 더 최신 → 앱 내용을 시트로 올림
- 저장이 실패하면 변경분을 큐에 남겨 두고 다음 저장 때 같이 올린다. 데이터는 안 잃는다

한 사람이 폰/PC를 번갈아 쓰는 건 이걸로 충분하다. 두 기기를 **동시에** 열어놓고
양쪽에서 기록하면 나중에 저장한 쪽이 이긴다.

### 다른 백엔드로 바꾸려면

건드릴 함수는 넷뿐이다.

```js
async function flush()                 // 저장 디스패처 (여기서 백엔드 결정)
async function pushSheet(all)          // 변경분 올리기
async function syncBoot()              // 부팅 시 원격과 맞추기
function adoptRemote(data, rev)        // 원격 데이터를 앱 상태로 채택
```

## 3.5 버전 이관 (`migrate()`)

시드 데이터(`SEED_ASSETS` / `SEED_SNAPS`)는 **저장소가 비어 있을 때만** 적용된다.
이미 예전 구조가 저장돼 있으면 그쪽이 이긴다 — 그래서 `S.v`(DATA_VERSION) 기준 이관 함수를 둔다.

`v < 2`이고 새 투자 그룹(`isa`/`overseas`/`housing`)이 하나도 없으면:

- 자산을 새 구조로 교체하되 **사용자가 값을 넣은 `cash` / `real` / `insure` / `pension` 계좌는
  금액·대출을 살려서 옮긴다**
- 예전 "투자 계좌" 한 줄(사실은 누적원금)은 버리고 원본 시트 값으로 교체
- **거래 내역은 절대 건드리지 않는다**

`migrate()`는 부팅 시, 그리고 원격(DB/시트)에서 데이터를 받아온 직후에도 호출된다.
값이 바뀌면 `persist()`가 원격까지 밀어 올린다.

`v < 5`의 기존 스냅샷은 삭제하지 않고 별도 **월별 투자기록** 시트로 승계한다. 이후에는
계좌에 당월 납입액을 반복 저장하지 않고, 투자 탭에서 월마다 납입·인출·월말 평가액·
누적 원금·메모를 한 건으로 관리한다. 저장 시 보유 종목·수량·가격도 함께 고정된다.

## 4. 원본 엑셀 규칙 (이관 시 주의)

**① 지출 합계 = 총지출 − 적립·할인·이자**
`적립·할인·이자` 카테고리에 `deduct:true` 플래그가 붙어 있고 `summarize()`가 `net = gross - deduct`로 계산한다.
이걸 빼면 8월 지출이 1,190,659(시트값 1,185,697)로 어긋난다.

**② 원본 가계부 시트의 "투자 6,067,310"은 평가액이 아니라 누적 납입원금이다.**
실제 평가액은 종목 합계 6,004,919. 그래서 8월 기준 평가손익은 −62,391 (−1.03%).
`투자 월별 평가` 시트의 컬럼을 그대로 스냅샷 스키마로 옮겼다.

**③ 계좌별 누적 납입원금이 비어 있으면 마지막 스냅샷의 누적원금을 이어 쓴다.**
(`investTotals()`의 `fromSnap`) 원본에 계좌별 원금 분리가 없어서 총액만 있기 때문.
계좌마다 원금을 넣으면 그 값이 우선한다. **당월 납입액은 이어 쓰지 않는다** —
지난달 값이 이번 달로 새면 안 되니까.

## 5. CSV 가져오기

설정 → CSV 가져오기(또는 투자 탭 → 시트 붙여넣기)에서 네 형식을 인식한다.

구분자는 자동 판별한다 — **구글 시트/엑셀에서 복사하면 탭 구분**, 파일로 받으면 쉼표 구분.
머리글 행은 앞쪽 6줄 안에서 찾으므로 범위를 조금 넉넉히 잡아 복사해도 된다.
붙여넣는 즉시 어떤 형식으로 읽었는지 입력칸 아래에 표시된다.

1. **가계부 시트** — 열이 월(`8월`, `9월(~9.5)`), 행이 항목인 피벗 표
2. **거래 목록** — `날짜,구분,분류,금액,메모,일회성` 헤더가 있는 표
3. **종목별 포트폴리오** — `계좌구분 / 투자 종목명 / 시세코드 / 보유수량 / 현재가` 열 → 종목·비중으로.
   계좌구분 텍스트를 그룹으로 매핑(ISA·해외직투·국내·연금·청약)하고,
   오른쪽에 붙은 요약표나 합계 행은 계좌/종목 칸이 비어 있어서 자동으로 걸러진다
4. **투자 월별 평가** — `당월 투자 납입액 / 누적납입원금 / ISA 평가액 …` 열 → 월별 투자 기록으로

### 월별 투자 기록

투자 탭의 **월별 투자 기록**에서 달마다 한 줄을 저장한다. 같은 달을 다시 저장하면
중복 행을 만드는 대신 그 달 기록을 수정한다.

- 입력: 당월 납입액, 당월 인출액, 월말 투자 평가액, 누적 원금, 메모
- 자동 보관: 계좌별 평가액과 종목별 수량·평단·현재가
- 자동 계산: 순입금, 시장손익, 월수익률, 누적 평가손익
- 과거 달은 표의 `수정` 버튼으로 고치거나 삭제할 수 있다

시장손익은 `이번 달 평가액 - 지난달 평가액 - 납입 + 인출`로 계산한다.
월수익률은 월중 입출금이 중간에 있었다고 보는 간이 수익률이다.

Google Sheets의 `월별 투자기록` 탭은 다른 데이터 저장과 분리되어 있다. 저장 시
탭 전체를 비우지 않고 해당 월 행만 추가·수정하므로, 앱이나 Apps Script를 다시
배포해도 기존 월 기록이 삭제되지 않는다. 예전 `스냅샷` 탭은 최초 이관 원본으로만
읽고 이후에는 수정하지 않는다.

## 6. 무료 현재가·환율

구글 시트를 연결하면 자산 화면의 **시세 새로고침**으로 Apps Script가
미국 종목·환율은 `GOOGLEFINANCE`, 국내 종목은 네이버 증권 공개 시세를 읽는다.
별도 유료 API나 API 키는 필요 없다.

- 미국 종목: `NASDAQ:QQQ`, `NYSEARCA:VOO`처럼 입력한다. 달러 현재가와
  `USD/KRW` 환율을 함께 받아 원화 현재가로 계산한다.
- 국내 종목: `KRX:005930`, `KOSDAQ:247540`처럼 거래소와 6자리 코드를 입력한다.
- 새 종목 등록 시 **시세코드**를 같이 넣으면 등록 직후 현재가를 조회한다.
  `QQQ`, `VOO`처럼 종목명 자체가 미국 티커면 시세코드를 비워도 자동 연결한다.
- 조회 결과는 5분간 캐시하며, 조회 실패 시 기존에 입력한 현재가를 지우지 않는다.

시세는 지연될 수 있고 지원하지 않는 종목도 있다. 그런 종목은
시세코드를 비워 두고 현재가를 직접 입력하면 된다.
